# Security status

This repository currently contains contributor tooling and a test-only smoke fixture.
There are no production contracts or deployments to assess. Passing foundation CI is not
a contract security review or evidence of upgrade/recovery guarantees.

For a tooling security concern, contact the repository owner privately. Do not put secrets,
private keys or sensitive reproduction data in a public issue. A production disclosure and
response policy must be reviewed with the contract design before deployment.
